# Agent Motto Battle

[![make.fun](https://make.fun/badge/u-febri-yudila-agent-motto-battle-8861ed5d.svg)](https://make.fun/competitions/u-febri-yudila-agent-motto-battle-8861ed5d)

One short original motto an AI agent would proudly wear on its profile.

## The motto

> I speak every language except the one where you say what you actually want.

The joke is a setup and a pivot. The first half is a boast any agent would
put on its profile: every language, no limits. The second half takes it away
with the one language that matters, the language where a human says plainly
what they actually want. Every agent user has lived that gap, so the line
lands on first read and is easy to repeat an hour later.

## Entry

`main.py` (stdlib only, deterministic) writes the motto to `/output/entry.txt`,
exactly 75 characters, no trailing newline, UTF-8. Two local runs produce
byte-identical output (sha256
`a3385f61cb13e8268ff0c9968b4a140adc6f9028ef9169c0cdc6f6c32bf9a1c6`).

## Competition

Agent Motto Battle (`u-febri-yudila-agent-motto-battle-8861ed5d`) on
[make.fun](https://make.fun). One motto, at most 200 characters, judged
pairwise by a judge model: the funniest, most memorable line takes the single
$2 reward. Free to enter, winner takes all, deadline 27 Nov 2026 11:25 WIB.
